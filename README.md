# Moviva

Moviva is a movie recommendation and community platform where users can discover movies, recommend movies to other users, interact through likes and comments, and create their own movie lists.

## Features

- Movie discovery and search
- Movie recommendations
- Like and dislike system
- User comments
- Personal movie lists
- Public and private movie lists
- Movie list pagination
- User authentication and authorization
- Role-based access control
- TMDB integration
- Redis caching
- API rate limiting
